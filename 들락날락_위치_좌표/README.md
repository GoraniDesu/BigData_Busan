## 데이터 수집 과정 및 한계점 안내

본 프로젝트에서 부산 어린이복합문화공간(들락날락)의 시설명과 주소 데이터는 들락날락 공식 사이트를 대상으로 웹 크롤링을 통해 실시간으로 수집하였습니다.  
최종적으로 분석에 활용된 데이터는 **2025년 6월 6일**에 마지막으로 수집된 정보를 기준으로 하며,  
이후 사이트 내 정보가 변경(신규 시설 추가, 명칭/주소 변경, 폐쇄 등)될 경우  
'들락날락 시설명 주소 수집코드.ipynb'코드를 마지막으로 수집된 날짜 이후에 실행하면 기존과 다른 결과(시설명, 주소, 좌표 등)가 출력되거나 코드가 정상적으로 동작하지 않을 수 있습니다.

이는 웹 크롤링 방식의 특성상,
- 웹 크롤링을 통해 최신화된 정보를 수집할 수 있지만, 마지막으로 수집한 날짜 기준으로 코드를 실행해도 일부 주소가 정상적으로 좌표 변환이 되지 않거나 중복된 들락날락 시설명이 나오는 문제가 발생하여, 중간에 수작업을 거치는 과정이 필요했습니다.
- 이로 인해 데이터 수집 이후의 변동 사항을 자동으로 반영하는 데 한계가 있었습니다.

따라서 본 프로젝트의 데이터 수집, 전처리, 분석 결과는  
**2025년 6월 6일 기준의 들락날락 시설명, 주소, 좌표 정보**를 기반으로 하였으며,  
현 시점에서 사이트의 정보가 달라졌을 경우 일부 결과가 상이할 수 있음을 참고해주시기 바랍니다.

이와 같은 한계로 인해 실시간 데이터 반영이 필요한 경우에는 일부 코드를 최신화된 결과에 맞게 수정하거나 별도로 수집·전처리하는 추가 작업이 필요합니다.

마지막으로 수집된 정보를 기준으로 전처리한 정보는 아래 폴더 경로에 저장되어 있습니다.
- 부산광역시 들락날락 주소 모음.csv
- 부산광역시_좌표추가.csv

- ../../Data_list/preprocessing_result/들락날락_위치_좌표_추출_복사본/부산광역시_좌표추가 복사본.csv
